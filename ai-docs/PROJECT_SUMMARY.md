# Project Summary

## Overview

**Build Card AI** (Frontend for Tech Self English) is a React-based web application designed to help users learn English through technology, specifically by creating and managing flashcards from content like YouTube transcripts.

## Technology Stack

- **Framework**: [React](https://react.dev/) with [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI Library**: [Chakra UI](https://chakra-ui.com/) (Components & Styling)
- **State Management**: [React Query (TanStack Query)](https://tanstack.com/query/latest) & React Context
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **Network**: [Axios](https://axios-http.com/)
- **Forms**: [Formik](https://formik.org/) & [Yup](https://github.com/jquense/yup)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)

## Key Features

- **Flashcard Management**: Create, read, update, and delete flashcards.
- **Transcript Integration**: Fetch and process transcripts (likely from YouTube) to generate learning materials.
- **Video Playback**: Integration with YouTube via `react-youtube`.
- **Responsive Design**: Built with Chakra UI for a responsive and accessible interface.
